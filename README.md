1. Nombre y descripción del proyecto
Sistema de Préstamos de Biblioteca
Es un programa realizado en Python que permite registrar y consultar los préstamos de materiales de una biblioteca

2. Problema que busca resolver
La biblioteca tiene dificultades para organizar sus préstamos porque utiliza registros manuales. Esto puede ocasionar pérdida de información, errores y confusiones
Por eso, se propone un programa que ayude a guardar y consultar los datos de los estudiantes y los materiales prestados

3. Funcionalidades implementadas
El programa permite:
- Registrar nuevos préstamos
- Ingresar el código y nombre del estudiante
- Registrar el material solicitado
- Indicar los días del préstamo
- Consultar los préstamos registrados
- Guardar la información en un archivo de texto
- Validar que los datos no estén vacíos
- Comprobar que los días sean un número entre 1 y 30

4. Instrucciones básicas de ejecución
- Python para desarrollar el programa
- Git para guardar los cambios del proyecto
- GitHub para publicar y compartir el código
